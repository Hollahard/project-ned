# Native socket adapter: next-session acceptance tests

Proposed tests only. This review reads the unchanged shared client at Hermes `649d6c0391029f35959cfbc240eb3534a6667cf5`; it does not implement a native adapter or qualify a gateway. Run the existing nineteen client tests first and then reuse their unchanged upstream imports with the real native adapter and an explicitly owned fixture peer.

| Boundary | Required observable result |
| --- | --- |
| Factory and event ordering | The factory returns one non-null socket synchronously. No event fires before listeners can attach. It must not return `undefined` on an invalid handle: upstream's nullish fallback constructs a browser WebSocket. Represent native setup failure with deferred error/close events; a thrown factory currently leaves the shared client in `connecting`. Prove that no browser network constructor is called. |
| Open and initial messages | `readyState` moves through browser-compatible numeric states. Successful authenticated upgrade emits `open` before any queued `gateway.ready` or RPC response, even when the server sends its first frame in the same read as the upgrade. The client's connect promise may resolve before gateway readiness; preserve that distinction. |
| Pre-open failures | Invalid owner, denied authentication, deadline, native cancellation and peer EOF each settle connect once, remove temporary listeners/timers and suppress later open/message delivery. A refused HTTP upgrade is not a received WebSocket close frame: do not invent a 4401/4403 wire close code. Use bounded sanitized diagnostics. |
| Post-open failures | Pipe/IPC loss, malformed frame, queue overflow and peer failure emit a terminal close event and reject pending RPCs. An error event alone is insufficient: the shared client removes its temporary error listener after open. Test graceful close separately from abnormal termination. |
| Send and bounds | `send` is synchronous from the shared client's perspective. It rejects a non-open socket or exhausted bounded queue immediately; native acknowledgement failures close the socket. Preserve send order, text message boundaries and newline-coalesced notifications. Budget UTF-8 bytes, not JavaScript character counts. No truncated frame may be delivered as successful JSON. |
| Listener and generation disposal | Honor `addEventListener`, `removeEventListener` and `{once:true}`. Closing or navigating fences new sends and releases native subscriptions. Delayed events from a retired socket cannot affect the new socket, including colliding IDs, error/close and a late backend request answer. Separate profile/backend generations keep separate clients. |
| Replay and cancellation | Exercise reconnect replay, epoch reset, truncated/unsupported replay, live/replay race, `open_requests` ordering and duplicate delivery through the actual adapter. Local AbortSignal still emits no wire cancellation. Test explicit session interruption separately at the future real-handler gate. Never retry an uncertain prompt automatically. |
| Owned end-to-end fixture | Through the actual Tauri event/command bridge, prove an unrelated listener receives zero application bytes, owned descendant acceptance, auth-before-upgrade, one absolute deadline, close during connect/send/read, bounded backpressure, root exit and descendant cleanup. Keep fixture transport evidence separate from real Hermes route/agent acceptance. |
