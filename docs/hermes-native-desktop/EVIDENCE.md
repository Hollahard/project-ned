## Source/documentation discrepancies resolved

| Topic | Stale or insufficient statement | Inspected source decision |
|---|---|---|
| Local Models availability | Some comments imply `--local`/canary only | Feature-flag implementation enables supported Windows |
| Default iteration cap | Agent guidance mentions 500 | `run_agent.py:241` uses `sys.maxsize`; the spec does not invent a 500-iteration default |
| Contract registration | Guidance says unknown methods are refused at import | `tui_gateway/server.py:885` registers; generator/completeness tests provide broader enforcement |
| Contract validation errors | All malformed params would become a generic validation error | Unknown keys are rejected directly; handlers preserve some existing domain errors |
| Cron memory | Guidance says cron skips memory | `cron/scheduler.py:2494` passes `skip_memory=False`; provider policies must inspect context |
| Memory index | SQLite/FTS could be mistaken for vector memory | Baseline FTS is lexical; vector search is an additive extension |
| Model activation/ejection | “Activate” means load and “eject” prevents reload | Current activate selects defaults; demand reload can follow eject; stop/latch semantics differ |
